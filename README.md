# Patina Studio

Downloads of **Patina Studio**, the desktop app of Restaurátorský ateliér
Patina for before/after photos of restored furniture.

Get the newest `PatinaStudio-Setup-x.y.z.exe` from the
[latest release](https://github.com/jakub-h/patina-studio-releases/releases/latest)
and run it. It installs for the current user, no admin rights needed. Windows
may show a SmartScreen warning the first time: choose "More info", then "Run
anyway".

An installed app tells you when a newer version is out and updates itself on
one click.

The app bundles SAM 3 by Meta (SAM License) and BiRefNet (MIT); the licence
texts are in the installed folder.
